> Upload a CSV → NexaIQ trains ML models, detects anomalies, writes GPT executive alerts, runs LangGraph agents, and answers plain English questions via Text-to-SQL — **no data team required.**

```
CSV Upload → Azure Blob → Kafka Event → Airflow DAG
    → DBT (RAW→CLEAN→MART) → AutoML (XGBoost/LightGBM/RF)
    → Anomaly Detection → GPT Alert → LangGraph Agents → Executive Report
                            ⏱️ Under 5 minutes. Zero human intervention.
```
